# 데이터 출처와 산출 방법

이 디렉터리에는 **분석에 실제로 사용한 집계 데이터만** 들어 있습니다.
원시 발전량 데이터는 용량이 크고 재배포 조건이 별도라 포함하지 않았고,
아래 절차대로 공공데이터포털에서 누구나 동일하게 내려받을 수 있습니다.

## 원시 데이터 재수집

| 데이터셋 | 공공데이터포털 ID | 용도 |
|---|---|---|
| 한국중부발전 태양광 발전량 | `15140015` | 발전소별 일자별 발전량 |
| 한국중부발전 소수력 발전량 | `15139102` | 출력제어·기상 요인 배제용 대조군 |

https://www.data.go.kr 에서 위 ID로 검색해 파일데이터(CSV)를 받은 뒤
`data/raw/` 에 두면 `src/relative_performance.py` 가 그대로 처리합니다.

## 각 파일 설명

`curtailment_by_genco.csv` — 발전 5사 신재생 출력제어 건수. 2024년 국정감사에
한국중부발전이 직접 제출한 자료 기준. 2년 누계 958건 중 중부발전 276건으로 최다.

`honam_curtailment_trend.csv` — 호남권 출력제어량 추이. 제주에 국한됐던 출력제어가
육지로 번지고 있다는 근거. 2021년 35 MWh(3회) → 2025년 83,944 MWh(171회).

`plant_relative_performance.csv` — 자사 태양광 13개소 상대성능 지수.
산출 방법은 아래 참조. 원시 발전량에서 `src/relative_performance.py` 로 계산.

`curtailment_headroom.csv` — 감축 약정 비율별 수용 가능 신규 부하.
Duke University Nicholas Institute의 2025년 연구 *Rethinking Load Growth* 수치.
미국 계통 기준이며 국내에 그대로 적용되지 않는다는 점은 본문에 명시했습니다.

`renewable_capacity_by_region_2022.csv` — 시도별 재생에너지 설비용량(MW).
전북·충남·전남 상위 3개 지역이 전체의 절반 가까이를 차지하는 편중 구조 확인용.

## 상대성능 지수 산출 방법

발전소별 절대 발전량을 그대로 비교하면 설비용량과 날씨가 섞여 의미가 없습니다.
그래서 **같은 날 전체 선단(fleet)의 이용률 평균을 100으로 놓고** 각 발전소의
이용률을 지수화했습니다.

```
이용률(i, d)   = 발전량(i, d) / 설비용량(i) / 24
상대성능(i, d) = 이용률(i, d) / mean_j( 이용률(j, d) ) × 100
상대성능(i)    = median_d( 상대성능(i, d) )
```

같은 날로 정규화하기 때문에 전국적 기상 변동과 계통 전체 출력제어는 상쇄되고,
**발전소 고유의 성능 차이만 남습니다.** 일 단위 중앙값을 쓴 것은 결측일과
정기점검 기간이 평균을 끌어내리는 것을 막기 위해서입니다.

이 방법으로 제주권 설비가 74~87로 뚜렷하게 열위인 것을 확인했고,
같은 날 제주 내 다른 설비는 정상 가동 중이었다는 사실로부터
기상·계통 요인이 아닌 설비 고유 요인이라는 결론을 얻었습니다.
